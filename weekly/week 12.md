## Topic 1. 할루시네이션(Hallucination)이란?

### 1. 핵심 개념 요약
LLM이 존재하지 않는 내용을 사실인 것처럼 지어내는 현상을 할루시네이션이라고 하며, 이는 LLM이 생성에만 집중을 하고 참/거짓 판별을 하지 않는다는 구조적 문제에서 발생하는 문제이다.

### 2. 상세 내용

#### 할루시네이션이란?
- LLM이 사실이 아닌 정보를 마치 진실인 것처럼 그럴듯하게 생성하는 오류 현상

#### 할루시네이션의 유형
- 사실적 오류: 존재하지 않는 것에 대해 마치 존재하는 것처럼 서술
- 논리적 모순: 앞서 말한 내용과 뒤에서 말하는 내용이 일맥상통하지 않는 경우
- 맥락 이탈: 질문과 전혀 관계없는 내용으로 답변

#### 할루시네이션의 원인
- 통계적 상관관계와 인과관계 혼동: 문장을 잘 생성하는 것에만 초첨 &rarr; 생성된 내용에 대한 참/거짓 구분하지 않음
- 학습 데이터의 편향성과 노이즈: LLM은 학습 데이터를 닮음 &rarr; 편견 및 노이즈에 노출
- 맥락 유지 한계 및 망각 현상: 대화가 길어질 수록 추반의 맥락을 망각하는 경향 

#### 왜 문제가 되는가
- 잘못된 정보의 확산
- 중요한 의사결정 과정에서의 오류 발생: 의료, 법률, 금융과 같은 전문적인 분야에서 더욱 취약
- AI 기술에 대한 전반적인 신뢰도 하락

## Topic 2. 할루시네이션 극복 시도 & 모델 스케일링 둔화

### 1. 핵심 개념 요약
할루시네이션을 극복하기 위한 방법으로 데이터를 개선하거나, 새로운 메커니즘을 도입하는 등의 방법들이 제시되었다.
좋은 모델을 만들기 위해서는 모델의 크기를 무분별하게 늘리기 보다는 연산량/파라미터 수/데이터 양의 균형을 잡는 것이 중요하며, 데이터의 품질 또한 중요하다.

### 2. 상세 내용

#### LLM 서비스들의 할루시네이션 극복 시도
| 접근 방식 | 설명 |
|------|------|
| 데이터 품질 개선 | 편향 및 노이즈 데이터 제외 |
| 사실 확인 메커니즘 | AI 출력을 신뢰 가능한 외부 소스와 대조 확인 |
| 불확실성 표현 | AI가 답변시 확신도를 함께 제시 |
| 다중 모델 앙상블 | 여러 AI 모델의 결과를 종합하여 답변 생성 |

#### 모델 크기 확장만으로 성능이 둔화되는 이유
- 스케일링 법칙(Scaling law)
  - 손실(loss)은 연산량/파라미터 수/데이터 양에 대해 거듭제곱으로 감소함 &rarr; 같은 크기의 성능 이동을 위해서 더 큰 노력이 필요함(멱법칙)
  - Chinchilla 스케일링 법칙: 파라미터 수와 데이터의 양은 비례해야하며, 파라미터만 늘리는 것은 비효율적
  - 무분별한 데이터 &rarr; 편향 + 노이즈, 고품질 데이터 &rarr; 유한함

## Topic 3. PEFT(Parameter-Efficient Fine-Tuning)

### 1. 핵심 개념 요약
PEFT는 사전학습된 LLM을 Fine-Tuning하는 방법으로, 가장 필요한 파라미터만 조정하는 방식이다.
그 예시로는 Adaptor, LoRA, QLoRA, Prompt-Tuning, P-Tuning 등이 있다.

### 2. 상세 내용

#### PEFT가 필요한 이유
- LLM 모델은 굉장히 크고 무겁기 때문에 Full Fine-Tuning을 하기에 막대한 자원이 필요

#### PEFT란?
- 파라미터를 효율적으로 활용한 Fine-Tuning 방법
- 사전학습된 LLM의 대부분의 파라미터 Freezing하고, 일부 파라미터만 Fine-Tuning
- 기법
  - 모델에 작은 모듈을 덧붙이는 방식: Adapter, LoRA, QLoRA(LoRA+양자화)
  - 입력 앞에 특별한 임베딩을 붙여 모델의 행동을 원하는 쪽으로 끌어오는 방식: Prompt Tuning, P-tuning

#### PEFT의 이점
- 효율성 향상: 관련성 높은 파라미터만 조정 &rarr; 자원 비용 절감
- 가치 창출 시간 단축: 새로운 작업을 위한 모델 업데이트 시간 단축
- 파괴적 망각 방지: 초기 파라미터 보존으로 초기 지식 망각을 방지
- 과적합 위험 감소: 대부분의 파라미터가 정적(freezing) 상태로 과적합 위험 적음
- AI 접근성 향상: 컴퓨팅 자원이 부족한 중소규모 조직도 활용 가능
- 유연한 AI: 개별 사용자에 맞게 모델 최적화 용이
